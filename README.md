# mendelcheck — 孟德尔家系单基因座可行性 / 最小冲突 / 最小代价指派

离线遗传数据校验的可复用模块：对单个二等位位点校验家系硬观测的孟德尔一致性；
可选地为每人提供“选择基因型 0/1/2 的三项非负整数代价”（`None` 表示禁止），
在严格传递约束下求全家系总代价最小的指派、列出每人的**全部最优可行基因型**，
并给出一份确定性见证。硬观测不一致时仍定位最少需移除的观测集合并给出修正见证。

仅做单个位点的经典孟德尔离散校验：**不**做多位点亲缘推断，**不**声称临床诊断。

## 环境

- Python 3.14.7，仅标准库，**无需安装任何第三方依赖**（`requirements.txt` 为空约定说明）。
- Linux 原生运行；核心、测试、演示全部离线，不需要网络、账号、数据库或 Docker。

## 接口

```python
from mendelcheck import check, CheckResult, ConflictReport, ValidationError

# 旧模式（无代价，向后兼容）
result = check(pedigree, observations, *, node_budget=100_000)

# 新模式（每人可选三项非负整数代价；None=禁止）
result = check(pedigree, observations, *, costs=costs, node_budget=100_000)
```

### 输入契约

- `pedigree: dict[str, tuple[str | None, str | None]]`
  键为个体 ID（非空 `str`，**至多 20 人**），值为 `(父亲ID或None, 母亲ID或None)`。
  父母 ID 必须引用家系内成员；亲子图必须**无环**。
  缺失父母（`None`）对每个子女、每个亲本槽位视为**独立未知创始者**，
  身份规则与旧模型完全一致；合成创始者不承担代价。
- `observations: dict[str, int]`
  个体 ID → 硬观测基因型（替代等位计数），严格 `int` 且取值 `0/1/2`；
  未观测个体基因型未知，可取三者。
- `costs: dict[str, tuple[int | None, int | None, int | None]] | None`（可选）
  个体 ID → `[选 0 的代价, 选 1 的代价, 选 2 的代价]`。每项为非负严格 `int`
  （拒绝 `bool`/`float`/负数），或 `None` 表示**禁止**该基因型；未列出的个体
  三项代价均为 0（均不禁止）。

  **硬观测先限制候选，再加代价**：同一人同时有硬观测时，先把候选限制为观测值，
  再取该值的代价。若观测值恰被该人代价表以 `None` 禁止，则该观测只能作为
  冲突被最小移除——高代价或禁止绝不会让冲突观测“偷偷”通过。
- `node_budget: int`（关键字参数，默认 `100_000`）
  整个 `check` 调用共享的搜索节点预算，须为 `int >= 1`。

### 返回 `CheckResult`

| 字段 | 含义 |
|---|---|
| `status` | `"feasible"` / `"optimal"` / `"infeasible"` / `"unknown"` |
| `feasible_genotypes` | `feasible` 时为每人全部可行基因型；`optimal` 时与 `optimal_genotypes` 相同；否则 `None` |
| `conflict` | 证明硬观测冲突无解时的 `ConflictReport`；否则 `None` |
| `nodes_used` | 实际消耗的搜索节点数 |
| `optimal_genotypes` | `optimal` 时：每人在某个最优指派中可取到的基因型集合（并集），覆盖全部个体 |
| `optimal_cost` | `optimal` 时已证明的最小总代价（非负整数） |
| `witness` | `optimal` 时为字典序确定见证；`unknown` 且已找到可行解时为**可行上界见证** |
| `witness_cost` | 上界见证的总代价（不保证最优） |
| `infeasible_reason` | 结构性不可行（如三人全禁）的原因字符串；否则 `None` |

### 状态语义

- **`feasible`**：未提供 `costs`（旧模式），已找到可行指派并枚举全部个体的
  可行基因型。旧调用方无需任何改动。
- **`optimal`**：提供了 `costs` 且已**证明**最小总代价。
  - `optimal_genotypes` 给出每人在“某个最优指派”中可取到的全部基因型（并集）；
  - `witness` 在所有最优指派中按人物 ID（`sorted`）序列上的基因型字典序取
    最小者，结果完全确定，`witness_cost == optimal_cost`。
- **`infeasible`**：证明无解，与预算耗尽严格分开。
  - 移除全部硬观测后仍无解（例如某人三个基因型全部被 `None` 禁止）：
    `conflict=None`、`infeasible_reason` 给出结构性原因；
  - 否则 `conflict` 为最小硬观测移除报告。提供了 `costs` 时，其中每个修正
    见证在其对应前提下还保证总代价最小，并按人物 ID 字典序唯一确定。
- **`unknown`**：节点预算耗尽，未证明最优性。若已找到可行指派，则
  `witness`/`witness_cost` 仅为一份**可行上界**（可能次优）；
  `optimal_genotypes` 与 `optimal_cost` 必为 `None`——未证明最优时绝不
  输出未经证明的“所有最优”。

`ConflictReport`：

- `removals: tuple[str, ...]` —— 一个最少需移除的硬观测 ID 元组（升序；在所有
  最小基数移除集中取字典序最小者，结果确定）。
- `alternatives: tuple[tuple[str, ...], ...]` —— 其余同基数最小移除集。
- `witnesses: dict[str, dict[str, int]]` —— 每个被移除观测 ID → 一份完整基因型
  指派，满足全部孟德尔约束及“原观测减去包含该 ID 的首个最小移除集”后保留的
  观测（有代价时还总代价最小、字典序最小），即修正后的重新可行见证。
- `truncated: bool` —— 最小移除集总数超过 `MAX_MINIMAL_SETS`（256）被截断。

### 错误语义

非法输入抛出 `ValidationError`（`ValueError` 子类），消息定位到具体个体/字段：

- 基因型非 `int`（拒绝 `bool`、`float`、`NaN`、`Infinity`）或不在 `{0,1,2}`；
- 代价序列长度不为 3、引用未知个体、元素为负/`bool`/`float`/`NaN`/`Infinity`；
- `node_budget` 非 `int`、为 `bool` 或 `< 1`；
- 家系为空、超过 20 人、ID 非法、父母引用未知成员、亲子图有环（报出环路径）；
- 观测或代价引用未知个体。

不做任何静默纠正；`check` 为纯函数式调用，失败不会留下部分变更的状态。

## 设计取舍

- **约束传播（AC-3）+ 分支搜索**：每个 (父, 母, 子) 三元约束预计算合法三元组
  （位掩码表示），传播收缩域后按最小域变量分支。每个递归调用计 1 个节点，
  预算在整个 `check` 调用内共享。
- **代价最优（分支定界）**：维护当前最优总代价，以“各实个体域内最小代价之和”
  为下界剪枝；合成创始者代价恒为 0。证明最优后，对每人每个候选值做一次
  “总代价恰为最优值”的等值存在性检查（含可达代价和剪枝），精确求出全部
  最优可行基因型；字典序最小见证通过按 `sorted` 人物 ID 逐位固定最小可行值
  得到。
- **预算语义**：预算只中断搜索。找不到可行解时，先用零节点的弧一致判断
  结构性不可行（如全部基因型被禁）；再尝试最小移除定位。任何中途耗尽都只
  返回 `unknown`，有可行解时附带明确标注为“上界”的见证，从不伪称最优。
- **最小冲突定位**：沿用 Reiter 碰撞集搜索——删除式极小化求极小冲突，在其
  成员上分支构建碰撞树，枚举全部最小基数移除集（上限 256，超出置
  `truncated`）。有代价时，每个保留观测集合下的见证取最小代价版本。
- **缺失父母**：每个 (子女, 缺失亲本槽位) 引入一个独立合成创始者变量，
  严格实现“独立未知创始者”语义；它们不进入代价与输出。

## 已知限制

- 仅单二等位基因座、经典孟德尔传递；不建模突变、重组、外显率、多位点连锁
  或亲缘推断，不兼容 PED/LINKAGE 等行业格式，不提供临床诊断结论。
- 规模上限 20 人；最坏情况搜索为指数级，预算耗尽返回 `unknown` 而非错误结论。
- 最小移除集枚举上限 256 个（超出时 `truncated=True`，已返回集合仍保证最小基数）。
- 见证语义为“相对包含该观测的首个最小移除集重新可行”，不保证单独移除该
  观测即可行；有代价时见证在该前提下最小代价且字典序最小。

## 误差口径

本库输出全部为**精确离散结果**（基因型集合、ID 元组、整数指派与整数代价），
不涉及任何浮点计算，无数值误差、无容差判定。
