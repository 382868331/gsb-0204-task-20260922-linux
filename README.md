# mendelcheck — 孟德尔家系校验：单基因座最小冲突定位 + 多位点候选父母对分配

离线遗传数据校验的可复用模块：

1. 对单二等位位点校验家系观测的孟德尔一致性；不一致时定位最少需移除的
   观测集合，并给出每个被移除观测的修正见证（`check`）。
2. 在每个孩子有限的候选父母对中，按**同一选择跨全部位点**的约束枚举可行
   分配；全部不可行时逐候选组合给出冲突位点（`assign_parents`）。

## 环境

- Python 3.14.7，仅标准库，**无需安装任何第三方依赖**（`requirements.txt` 为空约定说明）。
- Linux 原生运行；核心、测试、演示全部离线，不需要网络、账号、数据库或 Docker。

## 接口

```python
from mendelcheck import (
    check, assign_parents,
    CheckResult, ConflictReport, AssignmentResult, ParentAssignment,
    ValidationError,
)

result = check(pedigree, observations, *, node_budget=100_000)
assignment = assign_parents(genotypes, candidates, *, node_budget=100_000)
```

## 接口一：`check` —— 单位点家系校验

### 输入契约

- `pedigree: dict[str, tuple[str | None, str | None]]`
  键为个体 ID（非空 `str`，**至多 20 人**），值为 `(父亲ID或None, 母亲ID或None)`。
  父母 ID 必须引用家系内成员；亲子图必须**无环**。
  缺失父母（`None`）对每个子女、每个亲本槽位视为**独立未知创始者**。
- `observations: dict[str, int]`
  个体 ID → 基因型。基因型为替代等位计数，严格 `int` 且取值 `0/1/2`；
  未观测个体基因型未知，可取三者。
- `node_budget: int`（关键字参数，默认 `100_000`）
  整个 `check` 调用共享的搜索节点预算，须为 `int >= 1`。

### 返回 `CheckResult`

| 字段 | 含义 |
|---|---|
| `status` | `"feasible"` / `"infeasible"` / `"unknown"` |
| `feasible_genotypes` | 可行时：`{ID: frozenset(可行基因型)}`，覆盖全部个体；否则 `None` |
| `conflict` | 证明无解时：`ConflictReport`；否则 `None` |
| `nodes_used` | 实际消耗的搜索节点数 |

`ConflictReport`：

- `removals: tuple[str, ...]` —— 一个最少需移除的观测 ID 元组（升序；在所有
  最小基数移除集中取字典序最小者，结果确定）。
- `alternatives: tuple[tuple[str, ...], ...]` —— 其余同基数最小移除集（多个最小解释）。
- `witnesses: dict[str, dict[str, int]]` —— 每个被移除观测 ID → 一份完整基因型
  指派。该指派满足全部孟德尔约束及“原观测减去包含该 ID 的首个最小移除集”后
  保留的观测，即修正后的**重新可行见证**。
- `truncated: bool` —— 最小移除集总数超过 `MAX_MINIMAL_SETS`（256）被截断时为 `True`。

### 状态与错误语义

- `"infeasible"` 是**证明无解**（搜索空间穷尽），`"unknown"` 是**节点预算耗尽**，
  两者严格分开，绝不混淆。
- 非法输入抛出 `ValidationError`（`ValueError` 子类），消息定位到具体个体/字段：
  - 基因型非 `int`（拒绝 `bool`、`float`、`NaN`、`Infinity`）或不在 `{0,1,2}`；
  - `node_budget` 非 `int`、为 `bool` 或 `< 1`；
  - 家系为空、超过 20 人、ID 非法、父母引用未知成员、亲子图有环（报出环路径）；
  - 观测引用未知个体。
- 不做任何静默纠正；`check` 为纯函数式调用，失败不会留下部分变更的状态。

## 接口二：`assign_parents` —— 多位点候选父母对分配

每个孩子从有限候选父母对中选定**一对**，该选择对全部位点生效，
不允许逐位点换父母。至多 **3 个孩子 × 每孩 3 组候选 × 4 个位点**，
组合数至多 27，全部枚举。

### 输入契约

- `genotypes: dict[str, dict[int|str, int]]`
  个体 ID → 位点键 → 基因型（0/1/2，严格 `int`，拒绝 `bool`/`float`/`NaN`）。
  位点键为**非 bool 的 `int` 或非空 `str`**，全体位点共 `1..4` 个；
  同一位点键在不同个体间视为同一位点。
  - **孩子**必须在**全部位点**上有观测；
  - **父母**可只在部分位点有观测（未观测位点可取 0/1/2），也可完全不出现
    （视为未观测创始者）。候选中的 `None` 槽位语义同 `check`
    （该槽位为独立未知创始者）。
- `candidates: dict[str, list[tuple[str|None, str|None]]]`
  孩子 ID → `1..3` 个候选父母对 `(父亲, 母亲)`；孩子数 `1..3`。
  同一孩子的候选对不得重复；父母不能是另一个被分配的孩子，
  也不能是孩子本人（多代分配不在本接口范围，单位点多代请用 `check`）。
- `node_budget`：同 `check`，整个调用共享，严格 `int >= 1`。

### 返回 `AssignmentResult`

| 字段 | 含义 |
|---|---|
| `status` | `"feasible"` / `"infeasible"` / `"unknown"` |
| `assignments` | feasible：**全部**可行组合，每个为每孩一个 `ParentAssignment` 的元组（按下标元组字典序）；否则 `()` |
| `conflicts` | infeasible：**每个被否决组合**一条，每孩一个 `ParentAssignment`（含 `loci_conflicts`）；否则 `()` |
| `loci` | 参与校验的全部位点键元组（int 按数值在前、str 按字典序在后） |
| `nodes_used` | 实际消耗的搜索节点数 |

`ParentAssignment` 字段：`child`、`pair_index`（该孩候选列表下标，0 起）、
`pair`（实际 `(father, mother)`）、`loci_conflicts`（该组合在此孩子的
三元组上不一致的位点键元组；可行时为空）。多个孩子的三元组只有在共享
被选父母时才互相耦合；冲突位点按使该位点不可行的**极小孩子子集**归因，
独立三元组冲突时只标记孩子本人。

### 状态与错误语义

- `"infeasible"` 表示全部候选组合都已穷尽且被否决；`"unknown"` 仅在
  节点预算耗尽时出现，两者严格分开。
- 非法输入抛 `ValidationError`，消息定位到具体孩子/位点/候选下标：
  孩子数或候选数越界、位点数超过 4、孩子缺位点观测、候选重复、
  父母是另一个孩子或孩子本人、位点键/基因型类型非法等。
- 纯函数式调用：不修改入参，失败无半更新状态。

## 设计取舍

- **约束传播 + 分支搜索**：对每个 (父, 母, 子) 三元约束做 AC-3 弧一致
  （27 个合法三元组预计算为位掩码），收缩域后按最小域变量分支。
  每个递归调用计 1 个节点，预算在整个 `check` 调用内共享。
- **可行基因型集合**：先弧一致预剪，再对每个个体每个候选值做一次可满足性
  检查（至多 20×3 次），精确给出每个个体在某完整解中可取到的值。
- **最小冲突定位**：Reiter 碰撞集算法——删除式极小化求得极小冲突，
  在其成员上分支构建碰撞树，按当前最优基数剪枝，枚举**全部**最小基数
  移除集（上限 256 个，超出置 `truncated`）。见证由确认可行性的那次求解
  直接产出，不额外消耗搜索。
- **缺失父母**：每个 (子女, 缺失亲本槽位) 引入一个独立合成创始者变量，
  严格实现题面“独立未知创始者”语义。
- **候选父母对分配**：枚举孩子的全部候选组合（至多 3³=27 个），逐组合、
  逐位点（至多 4 个）复用旧的单位点传播+分支求解器判定可行性。各位点
  之间除“同一对父母必须对全部位点成立”外无跨位点耦合，故逐位点与
  即可精确实现“同一选择跨全部位点”。不可行组合的冲突归因枚举孩子的
  全部子集（至多 2³=8 个），取使该位点不可行的极小孩子子集。在本接口的
  两层、二等位结构下可证明：若每个三元组单独可行，则组合必可行（每个
  可行三元组都允许共享父母取杂合 1，可传任意等位，故允许域之交非空），
  归因实际落到冲突三元组对应的孩子；子集枚举仍保留对共享父母联合
  结构的处理，且结果由随机穷举对照逐例核对。

## 已知限制

- 仅单二等位基因座、经典孟德尔传递；不建模突变、重组、外显率或多位点连锁，
  不宣称兼容任何行业标准格式（如 PED/LINKAGE）。
- 规模上限 20 人；最坏情况搜索为指数级，预算耗尽返回 `unknown` 而非错误结论。
- 最小移除集枚举上限 256 个（超出时 `truncated=True`，已返回的集合仍保证最小基数）。
- 见证语义为“相对包含该观测的首个最小移除集重新可行”，不保证单独移除
  该观测即可行（多个不相交冲突时单移除一个不充分）。
- `assign_parents` 只覆盖题面限定的两层分配（孩子 + 候选创始者父母，
  至多 3 孩、每孩 3 对、4 位点）；候选父母不能是另一个被分配的孩子。
  不做缺失亲缘的全局概率推断，冲突报告是按候选组合的位点级精确定位，
  不是最小移除集式的证明，也不枚举 27 种之外的假设。

## 误差口径

本库输出全部为**精确离散结果**（基因型集合、ID 元组、整数指派），
不涉及任何浮点计算，无数值误差、无容差判定。
