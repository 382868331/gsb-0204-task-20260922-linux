# mendelcheck — 孟德尔家系校验：单基因座最小冲突定位 / 多位点候选父母判定

离线遗传数据校验的可复用模块，提供两个公开入口：

1. **`check`**：对单二等位位点校验家系观测的孟德尔一致性；不一致时定位
   最少需移除的观测集合，并给出每个被移除观测的修正见证。
2. **`assign_parents`**（本次新增）：每个孩子给有限候选父母对（≤3 对），
   在多个位点（≤4）上枚举候选分配（孩子 ≤3）；**同一对父母一经选定即
   贯穿全部位点，不允许逐位点更换**，返回可行联合分配或每个分配的冲突
   位点。复用与 `check` 完全相同的孟德尔规则与求解内核。

## 环境

- Python 3.14.7，仅标准库，**无需安装任何第三方依赖**（`requirements.txt` 为空约定说明）。
- Linux 原生运行；核心、测试、演示全部离线，不需要网络、账号、数据库或 Docker。

## 接口

```python
from mendelcheck import (
    check, assign_parents,
    CheckResult, ConflictReport, AssignmentResult, AssignmentConflict,
    ValidationError,
)

result = check(pedigree, observations, *, node_budget=100_000)
```

### 输入契约

- `pedigree: dict[str, tuple[str | None, str | None]]`
  键为个体 ID（非空 `str`，**至多 20 人**），值为 `(父亲ID或None, 母亲ID或None)`。
  父母 ID 必须引用家系内成员；亲子图必须**无环**。
  缺失父母（`None`）对每个子女、每个亲本槽位视为**独立未知创始者**。
- `observations: dict[str, int]`
  个体 ID → 基因型。基因型为替代等位计数，严格 `int` 且取值 `0/1/2`；
  未观测个体基因型未知，可取三者。
- `node_budget: int`（关键字参数，默认 `100_000`）
  整个 `check` 调用共享的搜索节点预算，须为 `int >= 1`。

### 返回 `CheckResult`

| 字段 | 含义 |
|---|---|
| `status` | `"feasible"` / `"infeasible"` / `"unknown"` |
| `feasible_genotypes` | 可行时：`{ID: frozenset(可行基因型)}`，覆盖全部个体；否则 `None` |
| `conflict` | 证明无解时：`ConflictReport`；否则 `None` |
| `nodes_used` | 实际消耗的搜索节点数 |

`ConflictReport`：

- `removals: tuple[str, ...]` —— 一个最少需移除的观测 ID 元组（升序；在所有
  最小基数移除集中取字典序最小者，结果确定）。
- `alternatives: tuple[tuple[str, ...], ...]` —— 其余同基数最小移除集（多个最小解释）。
- `witnesses: dict[str, dict[str, int]]` —— 每个被移除观测 ID → 一份完整基因型
  指派。该指派满足全部孟德尔约束及“原观测减去包含该 ID 的首个最小移除集”后
  保留的观测，即修正后的**重新可行见证**。
- `truncated: bool` —— 最小移除集总数超过 `MAX_MINIMAL_SETS`（256）被截断时为 `True`。

### 状态与错误语义

- `"infeasible"` 是**证明无解**（搜索空间穷尽），`"unknown"` 是**节点预算耗尽**，
  两者严格分开，绝不混淆。
- 非法输入抛出 `ValidationError`（`ValueError` 子类），消息定位到具体个体/字段：
  - 基因型非 `int`（拒绝 `bool`、`float`、`NaN`、`Infinity`）或不在 `{0,1,2}`；
  - `node_budget` 非 `int`、为 `bool` 或 `< 1`；
  - 家系为空、超过 20 人、ID 非法、父母引用未知成员、亲子图有环（报出环路径）；
  - 观测引用未知个体。
- 不做任何静默纠正；`check` 为纯函数式调用，失败不会留下部分变更的状态。

## 接口：`assign_parents`（多位点候选父母判定）

```python
from mendelcheck import assign_parents, AssignmentResult, AssignmentConflict

result = assign_parents(profiles, candidates, *, node_budget=100_000)
```

### 输入契约

- `profiles: dict[str, dict[str, int]]`
  个体 ID（非空 `str`，**至多 20 人**）→ 位点档案。位点名须为非空 `str`，
  **位点 1..4 个**；所有个体必须给出**完全相同的位点集合**。
  基因型同为严格 `int`、取值 `0/1/2`（拒绝 `bool`、`float`、`NaN`、`Infinity`）。
  允许存在既不是孩子也不出现在任何候选对中的“中性”档案个体。
- `candidates: dict[str, list[tuple[str, str]]]`
  孩子 ID → **1..3 个** `(父亲ID, 母亲ID)` **有序**候选对（`(F,M)` 与
  `(M,F)` 视为不同对）；孩子 **1..3 个**，其 ID 与候选父母 ID 都必须在
  `profiles` 中；同一孩子的候选对不可重复。
  候选父母不接受 `None`：档案之外的未知创始者无法检验。
  任意“每孩子选一对”的联合选择形成的亲子图都必须**无环**（含自环），
  否则输入非法（报出导致成环的选择）。
- `node_budget: int`（关键字参数，默认 `100_000`，须 `int >= 1`）
  全部位点、全部联合分配共享的搜索节点预算。

### 语义

枚举每个孩子选定一对父母的全部联合分配（笛卡尔积，至多 3³=27 个）；
对每个分配，在**每一个位点**上把全部档案当作观测、构造完整家系后调用与
`check` 相同的传播+搜索内核判定可行性。**一个分配里每个孩子的父母对是
唯一的，必须在全部位点同时成立**；逐位点换对即使各对在各自位点相容也
判为不可行。

### 返回 `AssignmentResult`

| 字段 | 含义 |
|---|---|
| `status` | `"feasible"` / `"infeasible"` / `"unknown"` |
| `feasible_assignments` | 可行时：非空元组，每项为 `{孩子ID: (父, 母)}` 的完整联合分配；否则 `()` |
| `conflicts` | 不可行时：每个被证伪分配的 `AssignmentConflict`；可行时 `()` |
| `nodes_used` | 实际消耗的搜索节点数 |

`AssignmentConflict`：

- `assignment` —— 该诊断对应的完整联合分配 `{孩子ID: (父, 母)}`；
- `feasible_loci` / `conflicting_loci` —— 该分配相容 / 被孟德尔规则直接
  证伪的位点名元组（不可行时每项至少有一个冲突位点）；
- `unknown_loci` —— 预算耗尽、未能判定的位点。

### 状态语义

- `"feasible"`：至少一个联合分配在全部位点可行（返回的每项都已逐位点
  证明；若预算在枚举后期耗尽，已返回的可行分配仍然有效，但**可能未穷尽
  全部可行分配**）。
- `"infeasible"`：全部联合分配均被证明至少在一个位点冲突（搜索穷尽）。
- `"unknown"`：尚未找到可行分配且预算耗尽；`conflicts` 给出已完成判定的
  分配，其中至少一项含非空 `unknown_loci`。
- 非法输入抛 `ValidationError`（`ValueError` 子类），消息定位到具体个体 /
  候选 / 位点；纯函数，不修改入参、不保留任何状态。

## 设计取舍

- **约束传播 + 分支搜索**：对每个 (父, 母, 子) 三元约束做 AC-3 弧一致
  （27 个合法三元组预计算为位掩码），收缩域后按最小域变量分支。
  每个递归调用计 1 个节点，预算在整个 `check` 调用内共享。
- **可行基因型集合**：先弧一致预剪，再对每个个体每个候选值做一次可满足性
  检查（至多 20×3 次），精确给出每个个体在某完整解中可取到的值。
- **最小冲突定位**：Reiter 碰撞集算法——删除式极小化求得极小冲突，
  在其成员上分支构建碰撞树，按当前最优基数剪枝，枚举**全部**最小基数
  移除集（上限 256 个，超出置 `truncated`）。见证由确认可行性的那次求解
  直接产出，不额外消耗搜索。
- **缺失父母**：每个 (子女, 缺失亲本槽位) 引入一个独立合成创始者变量，
  严格实现题面“独立未知创始者”语义。
- **候选父母判定**：至多 3³=27 个联合分配 × 至多 4 个位点 = 至多 108 次
  小规模 CSP 求解，直接枚举即可，无需额外概率或打分；每次求解都复用
  上述传播+搜索内核（每位点一次 `_validate_and_build`，无外部状态）。
  位点级诊断（好/坏位点）即枚举过程的副产物；冲突报告按**完整联合分配**
  给出而非按单个候选对，因为孩子可同时是他人候选父母（多代情形），
  跨孩子的共同约束可能使“单独看相容”的三人组在联合选择下不可行。
  枚举顺序确定（孩子按 ID 排序、候选按给入顺序），结果可复现。

## 已知限制

- 仅单二等位基因座、经典孟德尔传递；不建模突变、重组、外显率或多位点连锁，
  不宣称兼容任何行业标准格式（如 PED/LINKAGE）。
- 规模上限 20 人；最坏情况搜索为指数级，预算耗尽返回 `unknown` 而非错误结论。
- 最小移除集枚举上限 256 个（超出时 `truncated=True`，已返回的集合仍保证最小基数）。
- 见证语义为“相对包含该观测的首个最小移除集重新可行”，不保证单独移除
  该观测即可行（多个不相交冲突时单移除一个不充分）。
- `assign_parents` 只在给定候选集合内判定：既不推断档案外的未知父母，
  也不做亲缘概率 / 似然打分；候选父母必须为有完整档案的已知个体。
  两个亲本槽在遗传上对称，区别仅在于位置（第 1 个为父槽、第 2 个为母槽），
  不校验个体性别。
- `assign_parents` 预算在枚举后期耗尽时，`feasible` 下返回的可行分配
  均有效但可能不是全部；需要完整集合时应增大 `node_budget`。

## 误差口径

本库输出全部为**精确离散结果**（基因型集合、ID 元组、整数指派），
不涉及任何浮点计算，无数值误差、无容差判定。
